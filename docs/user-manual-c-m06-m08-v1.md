# 用户手册（C 模块）：仓储 / 生产 / 质量

> 版本 v1.0｜2026-11-14｜适用模块：M06 仓储管理、M07 生产执行、M08 质量管理
> 适用对象：车间仓管员、班组长、质检员、调度员
> 前置：已由管理员开通账号并分配角色权限；浏览器访问系统地址，登录后进入工作台。

---

## M06 仓储管理

### M06.1 仓库管理（菜单：仓储管理 → 仓库）

页面功能：维护仓库档案。仓库有类型（原料仓 raw / 成品仓 finished 等）。

操作步骤：
1. 点【新增】，填仓库编码（如 WH01）、名称、类型；成品发货仓勾选发货口库位。
2. 列表可按编码/名称搜索；【编辑】改名称与备注；仓库一旦被单据引用不可删除。

### M06.2 库位管理（仓储管理 → 库位）

每个仓库下设库位，收料口（is_receiving）与发货口（is_shipping）分别用于入库收货和出库发运。

操作步骤：
1. 选仓库 → 点【新增】填库位编码（如 A-01）。
2. 收料口/发货口开关按现场实际勾选。

### M06.3 采购入库（仓储管理 → 入库单）

入库流程：**建单 → 填明细 → 确认入库**。只有确认后才生成批次并写库存流水。

操作步骤：
1. 点【新增】：选仓库、供应商，逐行添加明细（物料、批次号、数量、库位、有效期）。
2. 保存后单据为"待确认"状态，单号自动生成（前缀 RK）。
3. 点【确认入库】：系统按明细生成批次（source_type=purchase）并写库存流水。
4. 已确认的单据不允许再改（重复确认会报错）。

常见提示：
- 13010 单据状态不允许确认 → 已经确认过或已作废。
- 13011 入库单没有明细 → 先添加明细行。

### M06.4 领料出库（仓储管理 → 出库单）

出库流程：**建单 → 确认出库**，系统自动按 FIFO 先进先出分配批次并扣库存。

操作步骤：
1. 普通领料：点【新增】选仓库，填明细（物料、数量）；单号自动生成（前缀 LL）。
2. 按工单领料：建单时带工单号（走"按工单领料"入口），物料消耗会挂到该工单。
3. 点【确认出库】：系统按 FIFO 依次扣减批次；任一物料可用量不足则整单失败。
4. 可在【库存流水】页查每笔扣减记录（biz_type=issue）。

常见提示：
- 13021 物料没有可用批次 → 先做采购入库。
- 13022 批次可用量不足 → 检查可用量（库存台账/可用量查询）。
- 13023 按工单领料必须带工单号。

### M06.5 库存台账与流水（仓储管理 → 库存台账 / 库存流水）

- **库存台账**：按批次展示当前结存（正数），含物料、入库日期、有效期、仓库；支持按物料/仓库/关键字筛选。
- **库存流水**：所有库存变动明细（入库/领料/退料/盘点调整/发货），是库存的"账本"，只读。
- **可用量查询**：`GET /inventory/stock/available/?material_ids=1,2,3`，按物料汇总代数和，供齐套检查使用（B 模块自动调用）。

### M06.6 库存盘点（仓储管理 → 盘点）

盘点流程：**建盘点单 → 录实盘数 → 确认 → 系统自动写调整流水**。

操作步骤：
1. 点【新增】选仓库，系统带出该仓各批次账面数；单号前缀 PD。
2. 在明细行填【实盘数量】，差异自动计算。
3. 点【确认盘点】：差异以 adjust 流水入账，账实自动对平。

常见提示：13030 状态不允许确认 / 13031 盘点单没有明细。

### M06.7 库存看板指标（供管理端）

- 库存周转率：`GET /inventory/stock/turnover/?days=30`，按物料给出期间出库量/平均库存与周转天数。
- 缺料预警：`GET /inventory/stock/shortage/?safety=100`，低于安全线的物料自动列出并给缺口数。

## M07 生产执行

### M07.1 开工 / 完工（生产执行 → 工单工序）

工序开工与完工由系统转发生产计划（planning）模块执行：

1. 班组长在工单详情选定工序（序号 + 工序类型）。
2. 点【开工】：工序状态置为进行中；点【完工】：置为已完成。
3. 若排产模块未上线，接口返回 13050（属预期，待 planning 上线后自动接通）。

常见提示：13051 工单下没有该序号的工序 / 13052 工序状态不允许该操作 / 13053 物料未到位（先完成领料）。

### M07.2 手机报工（手机端 → 扫码报工）

一线工人在手机上完成"开工 → 完工 → 报工"一条龙：

1. **开工**：选/扫工单工序，点【开工】记录开工时间。
2. **完工**：本工序做完点【完工】记录完成时间（这是换型计时与实际工时的依据）。
3. **报工**：填合格数量、不良数量（可按不良代码细分）、设备，提交。
4. 报错数量必须大于 0；写错的报工当班内可撤销。

报工撤销规则：只有**当班内且状态正常**的报工能撤销（报 13041 说明已过撤销期，走异常/盘点纠正流程）。

### M07.3 在制品看板（生产执行 → 在制品）

按工单汇总各工序在制数量与进度，来源为报工数据实时聚合，无需手工维护。

### M07.4 报工汇总（供计划员）

`GET /production/reports/summary/?work_order_id=<工单>`：返回各工序合格/不良数量、最近完成时间与合计，用于核对实际进度（B 模块甘特图调用）。

### M07.5 异常上报与关闭（生产执行 → 异常）

1. 异常发生时点【上报】：选工单/工序、异常类型、描述。
2. 处理完后点【关闭】填处理说明；重复关闭报 13060。

### M07.6 追溯查询（生产执行 → 追溯）

- **正向追溯**（物料批次 → 用到的工单/成品）：输入物料批次号。
- **反向追溯**（成品批次 → 用的物料与工序/检验）：输入成品批次号。
- 追溯数据由报工与检验自动写入，不需要手工登记。

## M08 质量管理

### M08.1 检验标准（质量管理 → 检验标准）

1. 新建标准（关联物料/产品），逐条添加检验项：名称、标称值、上下限、单位。
2. SPC 与检验判定读取标准项的规格限，上限/下限留空表示不参与该侧判定。

### M08.2 检验单（质量管理 → 检验单）

检验流程：**建单 → 录检验项数据 → 提交判定**。

1. 点【新增】关联物料批次与检验数量；单号前缀 JY。
2. 录入各检验项测量值（支持批量录入）。
3. 点【提交】：选判定结论。
   - 合格 passed / 不合格 failed / **让步放行 concession（必须填原因，报 13082 提示补填）**。
   - 合格数 + 不良数不能超过检验数量（报 13083）。
4. 判定结论唯一读 status 字段；下游（成品入库、发货）按它放行，不允许改单据回退判定。

### M08.3 视觉质检工作台（质量管理 → 视觉工作台）

1. 上传工件照片（jpg/png），点【开始检测】。
2. 系统返回：判定（DEFECT/OK）、置信度、缺陷框位置；可勾选"返回标注图"叠加显示。
3. 算法为 W6 训练的滑窗分类器（准确率 87.2%、漏检率 3.9%），参数可在【算法参数】页调整：
   - `detector`：lr（默认）/ rule（规则链）
   - `lr_stride`：滑窗步长（默认 32，越小越慢越细）
4. 物体识别页上传后返回多个目标外接框与中心坐标。

常见提示：13090 图像文件无效（换标准 jpg/png） / 13091 参数非法。

### M08.4 SPC 控制图（质量管理 → SPC）

1. 选检验项 → 页面绘制单值移动极差控制图（CL/UCL/LCL）。
2. 指标卡显示 Cp / Cpk（规格限取检验标准的上下限）、失控点数、超规格点数。
3. 抽样方案查询：`GET /quality/sampling/?lot_qty=500&aql=1.0&level=II`，按 GB/T 2828.1 简化表给出样本量与判定数。

### M08.5 不良代码（质量管理 → 不良代码）

维护不良类别字典（QC-01 划伤、QC-02 尺寸超差……），手机报工与检验单下拉引用，不许在页面硬编码新类别。

## 附：错误码速查（13000-13999 归 C 模块）

| 码 | 场景 | 含义 |
|---|---|---|
| 13000-13004 | 仓储基础 | 仓库/库位/批次不存在、物料必填、数量非法 |
| 13010/13011 | 入库 | 状态不允许确认 / 无明细 |
| 13020-13023 | 出库 | 状态不允许确认 / 无可用批次 / 可用量不足 / 缺工单号 |
| 13030/13031 | 盘点 | 状态不允许确认 / 无明细 |
| 13040-13042 | 报工 | 数量非法 / 不可撤销 / 记录不存在 |
| 13050-13053 | 工序 | 排产未就绪 / 工序不存在 / 状态不允许 / 物料未到位 |
| 13060 | 异常 | 已关闭 |
| 13070-13083 | 质量 | 标准不存在 / 检验单状态 / 让步缺原因 / 数量超检验数 |
| 13090/13091 | 视觉 | 图像无效 / 参数非法 |

> 通用提示：所有接口异常返回 `{code, message, data:null}`；页面顶部红色提示框显示 message，按上表定位。
