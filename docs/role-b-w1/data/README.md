## 二、怎么生成的（可复现）

1. 读 `商品销售数据.csv`（编码 UTF-8-BOM，字段 `date, store, item, sales`）。
2. 按 `W-SUN` 周桶聚合：`sales` 先按 `date→周`、再按 `item` 求和（10 个门店合计）。
3. 按 5 年总销量排序，取排名 **1 / 5 / 10 / 20 / 35 / 50** 的 6 个商品：`item 15 / 25 / 8 / 31 / 42 / 5`。
4. 量纲缩放：`件数 = round(销量 / K)`，**K = 100**（理由：使 6 种零件月需求约 1,089 件，落在理论产能 1,564 件/月的 70%）。
5. 按上表映射到产品编码，输出 UTF-8-BOM CSV。

- **不要把它当真订单**：教师数据是零售门店商品销量，本文件是"业务量纲映射"的派生数据，报告中必须写明（`../04-订单数据集评估-B.md` §4.3）。

- 重新生成时保持 `K=100`、同一批 item、同一周桶规则，否则历史实验指标不可比。
