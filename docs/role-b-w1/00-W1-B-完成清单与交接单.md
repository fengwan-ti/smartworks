## 7. 周五 5 分钟讲解关提纲（"数据从哪来、到哪去、需求变了改哪里"）

1. **数据从哪来**：工艺标准 → 工序模板（工时/设备类型/参数/检验）；产品主数据（A）→ 产品族 → 路线继承；D 的设备能力 → 排产匹配；动作分解 + D 经验 → 换型矩阵。
2. **数据到哪去**：`pr_route_step` → 排产 `pl_work_order_operation`（设备、人员、计划时间）→ 甘特图 / 产能负荷；`pr_bom_item` → 齐套检查 → 领料单（C）；路线工时 → 工时负荷（A）；排产结果 → AGV 时间窗（D，I-07）。
3. **需求变了改哪里**（举 3 个真实例子）：
   - 新增一种零件：配产品（A）→ 复制同族路线 → 改工时/参数 → 绑 BOM → 生效，**不改代码**；
   - 某工序标准工时改了：改模板或只在路线覆盖，不影响其他零件（覆盖字段为 null 才回落模板）；
   - 换型时间有实测了：导入 Excel 或逐条改 `changeover_minutes`，`source` 从 estimated 改 measured，排产下次自动生效。
4. **一个字段串到底**：`required_equipment_type = machining_center` 怎么让连接板 E 的下料工序从车床改到加工中心（路线层覆盖），以及为什么项目里没有锯床也能跑（数据配置，不改代码）。
