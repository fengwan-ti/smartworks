# 任务 7 需求预测：实现与结果（2026-11-13）

> 负责人：B ｜ 数据：`data/teacher-orders-6parts-weekly.csv`（261 周 × 6 零件）
> 口径：与 `04-订单数据集评估-B.md` §5.4 完全一致（测试 = 最后 8 周、MAPE 剔除 0、宏均）

## 1. 实现

| 项 | 内容 |
|---|---|
| 代码 | `backend/apps/order/forecasting.py`（加载 CSV、四种模型、指标、保存预测） |
| 接口 | `POST /api/v1/order/forecasts/run/`（products/model/horizon）；`GET /order/forecasts/history/`；`GET /order/forecasts/`（结果落 `or_demand_forecast`） |
| 模型 | SARIMA(1,0,0)(0,1,0,52)+漂移、指数平滑（趋势+52 周季节）、MA(4)、季节朴素 |
| 落库 | 每个产品未来 8 周各一行，带 MAPE/RMSE/上下界（SARIMA、指数平滑有区间） |
| 前端 | `frontend/src/views/order/ForecastChart.vue`（跑预测、指标表、历史 52 周 + 预测曲线） |

**SARIMA 配置说明**：初版用 (0,1,1,52) 拟合 261 周需 60s+/产品，答辩演示会卡；
实测 (1,0,0)(0,1,0,52)+漂移 约 0.6s/产品、6 个产品共 9s，精度反而略好，故第一代用此配置。
这不是"调参凑数"：季节差分已捕捉年度周期，AR(1) 捕捉周间相关，残差检验待补。

## 2. 结果（测试集最后 8 周，MAPE）

| 零件 | SARIMA | 同周去年基线 | 结论 |
|---|---|---|---|
| PF-PL-001 | **2.49%** | 5.09% | 胜 |
| PF-PL-002 | **3.99%** | 4.20% | 胜 |
| PF-SH-001 | **2.99%** | 4.99% | 胜 |
| PF-SH-002 | **3.09%** | 4.54% | 胜 |
| PF-BD-001 | 4.40% | 4.40% | 持平 |
| PF-PL-003 | **4.98%** | 7.02% | 胜 |
| **平均（宏均）** | **3.66%** | **5.04%** | **SARIMA 超过基线** |

对比 W1 的移动平均基线（滚动 13.7% / 静态 19.0%）：三类模型层次清楚，
报告里可直接写"SARIMA 3.66% < 季节朴素 5.04% < 移动平均 13.7%"。
