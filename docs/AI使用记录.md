# AI 使用记录

> 课程明确要求：使用大模型辅助的内容须在结课材料中给出使用说明及提示词附件。
> 每次使用 AI 生成或修改代码后，**当天**追加一条记录。不许事后补。

## 记录格式

| 字段 | 说明 |
|---|---|
| 日期 / 使用人 | 例：2026-04-15 / 成员 C |
| 角色与模块 | 例：C / inventory 批次与流水 |
| 提示词 | 贴原文，长提示词可编号后放附录 |
| AI 产出 | 生成了哪些文件、做了什么 |
| 人工修改 | 改了什么、为什么改 |
| 验证方式 | 怎么确认它是对的 |
| 结论 | 采用 / 部分采用 / 放弃 |
