## 五、A-4：DataScope 已写好，用法见下

```python
from apps.core.scopes import DataScope

qs = Equipment.objects.all()
qs = DataScope(Equipment).apply(qs, request.user)
```

或者视图里继承混入，一行都不用写：

```python
from apps.core.scopes import DataScopeMixin

class EquipmentViewSet(DataScopeMixin, viewsets.ModelViewSet):
    queryset = Equipment.objects.all()
    scope_field = 'workshop'
```

### 三条行为约定（**第 2、3 条与你的直觉可能不同，必看**）

| # | 约定 | 理由 |
|---|---|---|
| 1 | **超管全放行** | 老师要求；演示账号永远不会「看不到东西」 |
| 2 | **没声明 `scope_field` 的模型不过滤** | 渐进式接入。否则你 30 多个接口里漏写一个，就会出现「列表莫名全空但无报错」 |
| 3 | **取不到用户归属值时不过滤** | 例如模型按 `department` 隔离、但用户没填部门 → 返回全部而非空列表 |

**这三条是「可用性优先」的取舍，适用于第一代单车间演示。**
真做多车间权限要把 2、3 改成默认拒绝，并给 `User` 加 `workshop` 外键（现在只有 `department`）。

### 你的接口建议对照

| 你的接口 | 建议 |
|---|---|
| `equipments/` 列表与详情 | `scope_field = 'workshop'` |
| `road-nodes/` `road-edges/` | **不隔离**（路网全厂共用） |
| `finished-inbounds/` `shipments/` | 想按仓库隔离就写 `scope_field='warehouse'`，不想就留空 |
| `stock-aging/` `turnover/` | 同上 |

12 个测试覆盖了超管放行、普通用户真过滤、匿名拒绝、字段自动探测等情况，见 `apps/core/tests/test_scopes.py`。
