## 三、数据质量问题：标签有 6.4% 噪声（**必须处理**）

我逐文件核对过，**标签文件第一列的类别 id 与文件名前缀不一致的共 115 个文件**：

| 类别 | 图片数 | 标签干净 | 含噪声 | 空标签 |
|---|---|---|---|---|
| crazing | 300 | 295 | 5 | 0 |
| inclusion | 300 | 298 | 0 | 2 |
| pitted_surface | 300 | 263 | **37** | 0 |
| scratches | 300 | 255 | **45** | 0 |
| patches | 300 | 272 | **28** | 0 |
| rolled-in_scale | 300 | 298 | 0 | 2 |

**噪声形态**：大多是多出一个属于别的类别的框。例如 `patches_155.txt` 里既有 id=4（正确）也有 id=1（多余）。

### 处理规则（照这个做）

| 场景 | 做法 |
|---|---|
| **分类任务（任务 4）** | **类别一律取文件名前缀**，不看标签文件。1800 张全用 |
| **检测任务（任务 5）** | 只保留 `class == 文件名对应 id` 的框，其余丢弃 |
| 4 个空标签文件 | 分类任务保留，检测任务跳过 |

这样 **1800 张全部可用，不需要删任何图**。

## 五、两个任务的建议做法

### 任务 4：表面质量检测（分类）

| 项 | 建议 |
|---|---|
| 模型 | ResNet18 迁移学习即可，**不要自己从零搭**（200×200 小图，预训练权重很重要） |
| 输入 | 200×200 → 缩放到 224×224 |
| 划分 | 分层抽样 7:1.5:1.5，固定种子 |
| 指标 | 准确率 + **宏平均 F1** + 混淆矩阵（6 类混得最厉害的是哪两类要能说出来） |
| 报告要点 | 哪两类最容易混？为什么？（比如 patches 与 pitted 都是小面积斑点） |

### 任务 5：物体识别（检测）

| 项 | 建议 |
|---|---|
| 模型 | 先用 YOLOv8n 或 Faster R-CNN，小模型够用 |
| 数据 | 清洗后的 4108 个框（清洗后约 3900 个） |
| 指标 | mAP@0.5、各类 AP、**漏检率** |
| 报告要点 | 漏检率比 mAP 更重要——工业场景漏检一个缺陷品流到客户那里，代价远大于多检几个 |

**两个任务的关系**：分类（任务 4）回答"这是什么缺陷"，检测（任务 5）回答"缺陷在哪"。**现场演示时先给检测（画框），再给分类（报类别），视觉冲击最强。**
