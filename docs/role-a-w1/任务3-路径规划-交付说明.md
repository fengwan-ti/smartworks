## 二、函数签名与返回结构

### 2.1 `build_distance_matrix(nodes, edges)`

**入参**：直接喂你 `road-network-v1.json` 里的 `nodes` 和 `edges`（原始 list，不用转换）

**出参**：

```json
{
  "node_ids": ["N001", "N002", ...],
  "matrix": [[0, 1200, null, ...], ...]
}
```

| 约定 | 实现 |
|---|---|
| 行列顺序 | 按 `code` 升序 |
| 对角线 | 0 |
| 不可达 | **`null`**（Python 的 `None`） |

### 2.2 `find_shortest_path(nodes, edges, start, end)`

**出参**：

```json
{
  "start": "N001",
  "end": "N025",
  "path": ["N001", "N005", "N010", "N014", "N019", "N025"],
  "distance": 40434,
  "hops": 6,
  "algorithm": "dijkstra"
}
```

### 2.3 `plan_route(nodes, edges, start, stops, round_trip=False, max_stops=12)`

一次访问多个装卸点，最近邻构造 + 2-opt 改良。

**出参**：

```json
{
  "start": "N001",
  "order": ["N003", "N011", "N025", "N018"],
  "legs": [{"from": "N001", "to": "N003", "path": [...], "distance": 8312}, ...],
  "total_distance": 102300,
  "algorithm": "nearest_neighbor+2opt",
  "improved": true,
  "round_trip": true
}
```

### 2.4 `check_connected(nodes, edges)`

全通返回 `[]`，否则返回不可达点对 `[(起点, 终点), ...]`。
**路网导入时建议先跑这个**，不为空就抛 14503。

## 六、异常映射（你写接口壳子时照这个转）

| 我抛的异常 | HTTP | 业务码 | 消息 |
|---|---|---|---|
| `NodeNotFound(code)` | 400 | **14502** | 边引用了不存在的节点（或：节点不存在） |
| `UnreachableError(a, b)` | 400 | **14602** | 存在无法到达的任务（起终点不连通） |
| `check_connected()` 非空 | 400 | **14503** | 路网不连通，无法生成距离矩阵 |
| `ValueError`（目标点过多） | 400 | 14601 | 调度任务列表为空 / 参数超限 |

你只要：

```python
from apps.core.exceptions import BizError
from apps.algorithms.scheduling.path import NodeNotFound, UnreachableError

try:
    result = find_shortest_path(nodes, edges, start, end)
except NodeNotFound as e:
    raise BizError(14502, '节点不存在: %s' % e.code)
except UnreachableError:
    raise BizError(14602, '存在无法到达的任务（起终点不连通）')
```
