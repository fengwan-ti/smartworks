## 四、基线实验（已实测）

> 复现方式见 `docs/role-a-w1/基线实验复现说明.md`。以下数字均为本人实测，不是引用。

### 4.1 任务 4：图像 6 分类

| 项 | 数值 |
|---|---|
| 基线方法 | 7 维灰度特征（均值/标准差/5%与95%分位/水平与垂直梯度/极差）+ **最近质心分类器** |
| 验证方式 | 5 折交叉验证，固定随机种子 42 |
| **基线准确率** | **82.22%**（各折 84.2 / 83.1 / 80.8 / 80.6 / 82.5） |
| 随机猜测 | 16.67% |
| 各类召回 | crazing 0.80 / inclusion 0.89 / pitted 0.78 / scratches 0.77 / patches 0.86 / rolled-in 0.83 |

**→ C 的 CNN 目标：必须显著超过 82.2%。低于这个数说明不如"看灰度统计"，要重做。**

### 4.2 任务 6：设备三态识别（模拟数据）

| 项 | 数值 |
|---|---|
| 基线方法 | 单通道振动阈值（<1.5 normal / <2.5 wearing / 其他 abnormal） |
| 数据 | `data/equipment_sensor.csv`，12096 条 |
| **基线准确率** | **93.18%** |
| 随机猜测 | 33.3% |
| 各态振动中位 | normal 1.187 / wearing 1.751 / abnormal 3.528 |

**→ D 的目标：超过 93.2%。** 说明：三态在振动上分离度很高，简单阈值就能到 93%，所以**必须用更有说服力的指标**（宏平均 F1、异常类召回、提前预警时间），不能只报准确率。

### 4.3 任务 7：周需求预测

| 基线 | 微均 MAPE | 宏均 MAPE |
|---|---|---|
| MA(4) 移动平均 | **6.95%** | 6.95% |
| 同周去年 | **7.25%** | 7.25% |
| 各零件 MA(4) | 7.2 / 7.2 / 7.2 / 7.2 / 7.1 / 7.5 | — |

**→ B 的目标：MAE/MAPE 要低于 6.95%（即打败移动平均）。**

> ⚠️ **与 B 的 04 文档数字不一致，需 B 澄清。** B 报「MA4 18.9% / 同周去年 5.0%」，在同一份 `teacher-orders-6parts-weekly.csv` 上复算得到的是 6.95% / 7.25%。差异方向相反，请 B 在文档中补：①指标定义（微均/宏均）②算在哪份数据上 ③复现脚本或代码。
