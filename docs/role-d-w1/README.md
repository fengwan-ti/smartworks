## 三条最容易踩的

1. **坐标是设计值不是实测值**，答辩别说是车间实际布局。
2. **矩阵不对称是故意的**（主通道有一条单行道），不要当 bug 修。
3. **`step_type` 字典还没进契约**——值已定（B 全采纳），只差 A 落笔，在 `D契约补丁` §2。
