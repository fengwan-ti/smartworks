## 二、角色归档

各人的 W1 交付文档按角色分目录存放，避免和公共文档混在一起。

| 目录 | 谁 | 内容 |
|---|---|---|
| `role-a-w1/` | A（平台与集成） | 决定记录、任务 3 路径规划交付说明、给 B/C/D 的三份交接 |
| `role-d-w1/` | D（设备与物流） | **W1 入口见 `role-d-w1/README.md`**：评审意见、契约补丁、路网与设备台账口径、换型矩阵回执、工序复核 |
| `role-b-w1/` | B（工艺与计划） | 待建 |
| `role-c-w1/` | C（执行与质量） | 待建 |

> 约定：角色目录里放**已经发出去 / 已经生效**的文档，不放草稿。改了结论不要删原文，在文末加「结论追踪」或「更正」段落，保留判断过程。
