# 第一代非目标清单

> 目的：防止范围失控。任何人想加一项，先看这张表。
> **本清单已于 2026-10-26 由全员确认并冻结。**
> 确认方式：群里过一遍、无异议即视为通过（本组不做签字流程，以文件记录为准）。

## 一、明确不做

| 不做项 | 原因 | 移至 |
|---|---|---|
| 财务会计核算、总账、报表 | 会计规则复杂，与课程主线无关 | 不规划 |
| 完整采购流程（询价、比价、合同） | 只做"采购入库" | 第二代 |
| 完整销售流程（报价、合同、回款） | 只做"销售订单 + 发货" | 第二代 |
| 物料需求计划 MRP 展开 | 只做齐套检查 | 第二代 |
| 装配体与多层 BOM、装配工艺 | 只做单件加工 | 第二代 |
| 单件级（序列号）追溯 | 做到批次级 | 第二代 |
| 真实硬件接入 | 用模拟器 + 数据集 | 第二代 |
| Docker / CI-CD | 用双击式启动脚本 | 第二代 |
| 排班优化算法 | 人排班，系统只展示负荷 | 第二代 |
| 事件自动触发的滚动排产 | 手动点按钮触发重排 | 第二代 |
| 数字孪生 / 3D 车间 | 工作量远超范围 | 第三代 |
| 大模型自然语言助手 | 第一代不引入 | 第三代 |
