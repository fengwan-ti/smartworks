# 错误码总表

> 用途：四个人共用一张表，避免号段撞车。
> 规则：**号段按人和应用划分，不许占用别人的号段**；新增错误码先在本表登记再写代码。

## 一、号段分配

| 号段 | 归属 | 用途 |
|---|---|---|
| 10000-10099 | A（公共） | 参数校验、通用业务错误 |
| 10100-10199 | A（公共） | 数据不存在、状态不允许 |
| 10200-10299 | A（认证权限） | 未登录、令牌无效、无权限 |
| 10300-10399 | A（集成） | 数据导入导出、外部接口 |
| 11000-11999 | A（主数据） | 产品、物料、客户、车间、工位 |
| 12000-12999 | B（工艺与计划） | 工艺路线、BOM、订单、排产 |
| 13000-13999 | C（执行与质量） | 库存、生产、质量、视觉 |
| 14000-14999 | D（设备与物流） | 细分见下 |
| 19000-19999 | 算法 | 见第四节 |

## 五、使用约定

1. **错误码是契约的一部分**，新增必须先改本表，再写代码
2. `message` 一律用中文，写给最终用户看，不要写英文或堆栈
3. 同一含义只能有一个码，**不许两个码表示同一件事**
4. 前端靠 `code` 判断，**不靠 message 文本匹配**
