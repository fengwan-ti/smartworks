> 规则：**号段按人和应用划分，不许占用别人的号段**；新增错误码先在本表登记再写代码。

### 前端处理规则（重要）

**前端只判断 `code === 0` 为成功，其余一律用 `message` 提示，不依赖具体码。**
原因：错误码属于后端内部约定，将来细分或调整不应导致前端改代码。
`utils/request.js` 已经是这么实现的。

## 五、使用约定

1. **错误码是契约的一部分**，新增必须先改本表，再写代码
2. `message` 一律用中文，写给最终用户看，不要写英文或堆栈
3. 同一含义只能有一个码，**不许两个码表示同一件事**
4. 前端靠 `code` 判断，**不靠 message 文本匹配**
